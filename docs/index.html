Portes

Transpilador de Português Estruturado para C.

O Portes lê algoritmos escritos em Português Estruturado (arquivos .ptes) e gera o programa C equivalente. A ideia é ajudar quem está aprendendo lógica de programação em português a dar o próximo passo: ver, lado a lado, como cada comando que já conhece fica em C.

Começar Código no GitHub Downloads

Portes

// Lê dois números inteiros e mostra a soma.
ALGORITMO soma;
VARIAVEIS
  a, b, resultado : INTEIRO;
INICIO
  ESCREVA("Digite dois números:");
  LEIA(a, b);
  resultado <- a + b;
  ESCREVA(a, " + ", b, " = ", resultado);
FIM;

C gerado

#include <stdio.h>

/* ALGORITMO soma */
int main(void) {
    int a = 0, b = 0, resultado = 0;

    printf("Digite dois números:\n");
    scanf("%d", &a);
    scanf("%d", &b);
    resultado = a + b;
    printf("%d + %d = %d\n", a, b, resultado);
    return 0;
}

Instalação

Binário pronto

Baixe o executável para o seu sistema (Linux ou Windows, amd64 ou arm64) na página de releases. Para compilar o C gerado você também precisa de um compilador C, como gcc ou clang.

A partir do código-fonte

Requer Go 1.27+ e um compilador C (cc).

git clone https://github.com/kauanallyson/portes.git
cd portes
go build .        # gera o executável ./portes

Usando o compilador

./portes arquivo.ptes               # imprime o código C gerado
./portes -o saida.c arquivo.ptes    # grava o C em saida.c
cc -o prog saida.c && ./prog        # compila e roda
OpçãoO que faz
-o arquivo.cGrava o código C no arquivo indicado em vez de imprimir na tela.
-tokensImprime a lista de tokens encontrados pelo analisador léxico.
-astImprime a árvore sintática do programa.

As opções -tokens e -ast são úteis para estudar como um compilador funciona por dentro: dá para ver exatamente como o texto do programa é quebrado em pedaços e depois organizado em uma árvore.

Estrutura do programa

Todo programa Portes tem três partes: o nome, a declaração das variáveis e o corpo.

ALGORITMO nome_do_programa;
VARIAVEIS
  // declarações
INICIO
  // comandos
FIM;
  • ALGORITMO dá um nome ao programa. O nome vira um comentário no C gerado.
  • VARIAVEIS lista todas as variáveis que o programa usa, com seus tipos. Se o programa não usa variáveis, a seção pode ser omitida.
  • Entre INICIO e FIM; ficam os comandos, executados de cima para baixo.

Comandos simples (atribuição, LEIA, ESCREVA) terminam com ;. Nos fechamentos de bloco (FIMSE, FIMENQUANTO, FIMPARA) o ; é opcional.

Elementos léxicos

Comentários

Começam com // e vão até o fim da linha.

// isto é um comentário
x <- 10;  // comentário no fim da linha

Identificadores

Nomes de variáveis e do algoritmo começam com uma letra ou _, seguidos de letras, dígitos ou _. Apenas letras sem acento (a–z, A–Z) são aceitas em nomes: use media, não média.

Maiúsculas e minúsculas

As palavras reservadas são escritas em MAIÚSCULAS: SE é palavra reservada, mas se é um identificador comum. Nomes de variáveis também diferenciam maiúsculas de minúsculas: total e Total são variáveis diferentes.

Declaração

Na seção VARIAVEIS, cada linha declara um ou mais nomes, separados por vírgula, seguidos de :, do tipo e de ;. 

VARIAVEIS
  nome : STRING;
  n1, n2, n3, media : REAL;
  contador : INTEIRO;
  achou : LOGICO;

Toda variável começa com um valor “zerado”: 0 para números, "" para STRING e FALSO para LOGICO.

Regras de tipo

  • Toda variável usada precisa ter sido declarada, e só pode ser declarada uma vez.
  • Os tipos precisam bater. A única conversão automática é de INTEIRO para REAL: dá para guardar 3 numa variável REAL, mas não 3.5 numa INTEIRO.

Precedência

Da mais forte (avaliada primeiro) para a mais fraca. Use parênteses para mudar a ordem.

Divisão inteira. Como em C, INTEIRO / INTEIRO descarta a parte decimal: 7 / 2 dá 3. Para obter 3.5, faça um dos lados ser real: 7 / 2.0.

NAO pega a comparação inteira. NAO a = b significa NAO (a = b), e não (NAO a) = b.

Uma comparação por vez. a < b < c é erro; escreva a < b E b < c.

bissexto <- (ano MOD 4 = 0 E ano MOD 100 <> 0) OU ano MOD 400 = 0;
SE NAO bissexto ENTAO
  ESCREVA(ano, " não é bissexto");
FIMSE

Comandos

Atribuição <-

Guarda o valor de uma expressão numa variável. Lê-se “recebe”.

soma <- n1 + n2;
media <- soma / 2.0;
nome <- "Maria";
acertou <- FALSO;

Em C, a atribuição de STRING vira strcpy(nome, "Maria");.

LEIA

Lê valores digitados pelo usuário e guarda nas variáveis, na ordem.

LEIA(idade);
LEIA(n1, n2, n3);
  • Aceita variáveis INTEIRO, REAL e STRING. Não aceita LOGICO.
  • Em STRING, lê apenas uma palavra (para no primeiro espaço), até 255 caracteres.
  • Cada variável vira um scanf separado no C.

ESCREVA

Mostra na tela os valores, um após o outro, e pula linha no fim.

ESCREVA("Olá, mundo!");
ESCREVA("Média de ", nome, ": ", media);
  • Aceita qualquer expressão, de qualquer tipo.
  • Valores LOGICO aparecem como VERDADEIRO ou FALSO.
  • Os valores não são separados por espaço automaticamente: inclua os espaços nas strings.
  • Todos os argumentos viram um único printf no C.

SE … ENTAO … SENAO … FIMSE

Executa um bloco só se a condição (do tipo LOGICO) for verdadeira. O SENAO é opcional.

SE m >= 7 ENTAO
  ESCREVA("Aprovado");
SENAO
  SE m >= 4 ENTAO
    ESCREVA("Recuperação");
  SENAO
    ESCREVA("Reprovado");
  FIMSE
FIMSE

ENQUANTO … FACA … FIMENQUANTO

Repete o bloco enquanto a condição for verdadeira. A condição é testada antes de cada repetição.

a <- 0;
b <- 1;
ENQUANTO a <= 100 FACA
  ESCREVA(a);
  prox <- a + b;
  a <- b;
  b <- prox;
FIMENQUANTO

PARA … DE … ATE … [PASSO …] FACA … FIMPARA

Repete o bloco variando um contador do valor inicial até o final (inclusive).

PARA i DE 1 ATE 10 FACA
  ESCREVA("7 x ", i, " = ", 7 * i);
FIMPARA

PARA i DE 10 ATE 1 PASSO -1 FACA
  ESCREVA(i, "...");
FIMPARA
  • O contador precisa ser uma variável INTEIRO.
  • O PASSO é opcional (padrão 1) e deve ser um número inteiro constante diferente de zero, como 2 ou -1. Não pode ser uma variável.
  • Com passo positivo o laço continua enquanto i <= fim; com passo negativo, enquanto i >= fim.

Mensagens de erro

Os erros apontam o arquivo, a linha e a coluna. Quando há erro de sintaxe, o compilador para no primeiro; erros de tipo e de variáveis são todos listados de uma vez.

main.ptes:7:3: não é possível atribuir STRING a 'n1' (INTEIRO)

não é possível atribuir REAL a 'x' (INTEIRO)Tipos diferentes na atribuição.

Exemplos

A pasta examples/ tem 15 programas, do mais simples ao mais completo.

ExemploO que mostra

Programa completo: senha

// Pede a senha até acertar ou acabarem as tentativas. Compara STRINGs com =.
ALGORITMO senha;
VARIAVEIS
  tentativa : STRING;
  restantes : INTEIRO;
  acertou : LOGICO;
INICIO
  restantes <- 3;
  acertou <- FALSO;
  ENQUANTO NAO acertou E restantes > 0 FACA
    ESCREVA("Senha (", restantes, " tentativas):");
    LEIA(tentativa);
    SE tentativa = "portes123" ENTAO
      acertou <- VERDADEIRO;
    SENAO
      restantes <- restantes - 1;
    FIMSE
  FIMENQUANTO
  SE acertou ENTAO
    ESCREVA("Acesso liberado");
  SENAO
    ESCREVA("Acesso bloqueado");
  FIMSE
FIM;
